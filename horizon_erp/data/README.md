# Horizon demo data (CSV)

Generated by `horizon_erp.setup.demo_data.export_csvs()` from the Python data
structures in `horizon_erp/setup/demo_data.py`, which is the source of truth.
Column labels follow the Data Import template labels where practical; child-table
columns carry the child DocType in brackets.

## Import order

1. `cost_centers.csv` - Cost Center (parents before children)
2. `warehouses.csv` - Warehouse (groups before leaves)
3. `items.csv` - Item (Item Groups, UOMs and Suppliers must exist first)
4. `suppliers.csv` - Supplier (+ Address / Contact)
5. `customers.csv` - Customer (+ Address / Contact, credit limits)
6. `item_prices.csv` - Item Price (Price Lists Standard Selling / Standard Buying / North Selling)
7. `pricing_rules.csv` - Pricing Rule
8. `bom_lines.csv` - BOM (bottom-up: sub-assemblies before HZ-PUMP-100 / HZ-CONV-200)

GST rates per item group (Equipment 5%, Spares 12%, Components 5%, Raw Material /
Sub Assemblies 18%) come from the brief and must be confirmed against HSN by the client's CA.
